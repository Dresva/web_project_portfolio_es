# Portafolio personal - Andrés Villanueva

## Descripción

Este proyecto es mi portafolio personal como desarrollador Full Stack Junior.

El sitio presenta información sobre mi perfil profesional, habilidades y herramientas de desarrollo, así como algunos de los proyectos en los que he trabajado.

El objetivo del proyecto es contar con un espacio web donde pueda presentar mi experiencia, conocimientos y proyectos de desarrollo de software.

## Tecnologías y técnicas utilizadas

- HTML5
- CSS3
- Open Sans
- Archivo Black
- Flexbox
- CSS Grid
- Diseño responsive
- Media queries
- Git
- GitHub
- GitHub Pages

## Funcionalidades

- Presentación del perfil profesional.
- Sección de habilidades y herramientas.
- Sección de proyectos destacados.
- Enlaces a proyectos de GitHub.
- Enlaces a demostraciones de proyectos.
- Sección de contacto y redes sociales.
- Diseño adaptable para escritorio, tablet y dispositivos móviles.
- Efectos hover en elementos interactivos.
- Favicon personalizado.

## Proyecto

El diseño del portafolio está basado en el brief y diseño proporcionados para el Sprint 4 de TripleTen.
